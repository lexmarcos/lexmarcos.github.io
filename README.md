# markzuel

Portfolio de uma tela de Marcosuel Filho. Feito com Astro.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # gera dist/
```

- Conteúdo (textos, links, projetos): `src/data/profile.ts`
- Design system: `DESIGN.md` e `src/styles/tokens.css`
- Ícones: Solar via `astro-icon`. Marcas em `src/icons/` e Simple Icons.
